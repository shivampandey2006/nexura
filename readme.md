# Butter Paneer Masala Recipe

A simple recipe webpage for Butter Paneer Masala made using HTML and CSS.

## About

This project is a basic frontend practice project. It contains the recipe, ingredients, cooking steps, some useful details, and a recipe video.

The main focus of this project was to practice HTML structure and CSS styling along with making the page responsive.

## Features

* Butter Paneer Masala recipe
* Ingredients and cooking instructions
* Recipe details in a table
* Recipe video
* Hover effects
* Responsive design for smaller screens
* Simple and clean layout

## Technologies Used

* HTML
* CSS

## What I Practiced (HTML / CSS)

* Flexbox
* CSS hover effects
* Responsive design using media queries
* Image styling
* Tables and lists
* iframe for embedding a YouTube video
* Basic CSS transitions and animations

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it.
